# 📷 Capturas de la app

Deja aquí las capturas de pantalla con **estos nombres exactos**. En cuanto estén (súbelas al
repo o dime que ya están), las enlazo en el `README.md` principal en una pequeña galería.

## Nombres esperados

| Archivo | Pantalla a capturar |
|---|---|
| `bienvenida.png` | Pantalla de bienvenida (primer arranque) |
| `escaner.png` | Escáner / cámara con el marco guía |
| `coleccion.png` | Colección (con el widget de valor y los chips) |
| `detalle.png` | Detalle de una carta (efecto holográfico) |
| `mazos.png` | Sugerencias de mazo (tarjeta héroe + carrusel) |
| `valor-historico.png` | Gráfica del valor de la colección |

**Opcionales** (si quieres una galería más completa): `mazo-detalle.png` (mazo con badges de ban list),
`sets.png` (álbum por sets), `estadisticas.png`, `ajustes.png`.

> No pasa nada si al principio solo dejas 2 o 3; las enlazo igual y ampliamos después.

## Cómo tomar las capturas

- **En el emulador:** botón de **cámara** en la barra lateral de controles (guarda un PNG en tu equipo),
  o por terminal: `adb exec-out screencap -p > escaner.png`.
- **En un móvil:** pulsa a la vez **Bajar volumen + Encendido**; luego pasa el PNG al ordenador.

## Recomendaciones

- Formato **PNG**, pantalla completa del móvil (vertical).
- Que no pesen mucho: ~**1080 px de ancho** o menos suele bastar (idealmente < 500 KB cada una).
- Procura que la **colección tenga cartas** y algún **mazo creado**, para que se vean los chips,
  el valor y las sugerencias.
